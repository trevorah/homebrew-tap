# Trevorah Tap

## How do I install these formulae?

`brew install trevorah/tap/<formula>`

Or `brew tap trevorah/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "trevorah/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
